# 업체 공통 작업과 기본 단가

라벨 종류·자수 작업명은 업체별로 한 번 등록한 뒤 다른 스타일에서도 선택합니다. 작업명, 기본 사양, 기본 단가는 업체 기준 정보로 보관합니다.

## 처음 등록

1. 관리자 업체 설정에서 해당 업체의 업무 구분을 **라벨** 또는 **자수**로 지정합니다.
2. 스타일 상세의 **가공·품질 관리 → 라벨 관리 / 자수 관리**에서 담당 업체를 선택합니다.
3. **업체 공통 작업·기본 단가**의 공통 등록 버튼을 누르고 작업명·사양·기본 단가와 사유를 저장합니다.
4. **라벨 관리 시작 / 자수 관리 시작**에서 등록해 둔 항목을 선택합니다. 작업명·사양을 불러오며 작업을 저장할 때 업체 기본 단가를 스타일·컬러별로 보관합니다.

라벨·자수 업체는 로그인 후 오버뷰의 **내 업체 공통 작업·단가**에서 자기 업체의 목록을 직접 관리할 수 있습니다. 배정된 생산 스타일이 없어도 작업명·사양·기본 단가 등록과 수정이 가능합니다.

저장된 작업 목록은 다른 스타일과 새로고침 후에도 남습니다. 업체가 다르면 작업 목록과 기본 단가도 구분합니다. 기본 단가 빈칸은 미입력이고 `0`은 0원입니다.

## 단가 인상과 기존 작업

업체 기본 단가가 오르면 공통 작업·단가 수정에서 새 단가와 변경 사유를 저장합니다. 변경한 기본값은 **그 뒤 새로 선택하는 작업**에 적용합니다. 이전 스타일의 작업명·사양·합의 단가는 자동으로 바뀌지 않습니다.

특정 스타일·컬러의 단가만 바꾸려면 아래 **가공·품질 단가 관리**에서 개별 단가를 수정합니다. 이렇게 저장한 개별 단가는 업체 기본 단가를 바꾸어도 유지합니다. 을지는 저장된 해당 스타일·컬러·작업의 단가를 사용합니다.

현재 스타일의 담당 업체를 바꾸려면 작업 내역 수정을 열고 업체를 변경합니다. 편집 중인 작업을 다시 선택한다는 안내를 확인한 뒤 새 업체의 항목을 선택합니다. 저장된 이전 작업과 변경 사유는 이력에 보존합니다.

## 기존 자료와 적용

업체가 지정되지 않은 기존 전역 라벨·자수 목록은 **기존 공통 작업 목록 · 업체 미지정**으로 유지합니다. 기존 작업의 이름·사양·단가를 새 업체 기준으로 자동 변경하지 않습니다.

신규 업체 업무 구분은 SQL 020, 업체 공통 작업·기본 단가와 새 작업의 단가 보관은 SQL 021이 필요합니다. 이 개발 작업에서 운영 SQL은 실행하지 않습니다. 설정이 없는 서버에서는 준비 안내를 표시하고, 기존 목록·개별 단가 기능을 유지합니다.

업체 공통 작업·단가의 저장은 승인된 본사 계정과 해당 업체 계정만 허용합니다. 본사 작업 지시와 스타일의 생산·PO·입출고·마감 기록에 대한 기존 권한은 별도로 유지합니다.
