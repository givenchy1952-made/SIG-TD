# 프로젝트 명칭 다운로드 적용 범위

2026-10-30 기준 `src`와 `scripts`의 실제 파일 생성·다운로드 경로를 조사했습니다. `createObjectURL`, `download`, `writeBuffer`, `writeFile` 및 관련 다운로드 버튼을 확인했습니다.

## 고정 양식과 원본 보존

SIG 을지는 기존 고정 시트의 셀 위치를 옮기지 않습니다. A열 프로젝트 코드, C열 입고일, I열 전체 품번, N·R·T 금액 계산, U·V 부가세·합계 수식을 유지합니다. 프로젝트 명칭·코드·시즌·ID와 실제 을지 행의 대응은 별도 **프로젝트 안내** 시트에 표시합니다. 일반 마감 양식도 기존 입력 범위·수식·병합을 유지하고 별도 안내 시트를 추가합니다.

프로젝트 선택의 키는 이름이나 코드가 아닌 **기존 프로젝트 ID**입니다. 같은 명칭의 서로 다른 프로젝트도 함께 선택하거나 구분할 수 있습니다. 프로젝트 내 선택은 OR, 프로젝트와 스타일 선택은 AND로 적용합니다. 화면의 프로젝트·스타일·컬러 선택은 다운로드 창의 초기값이며, 창 안에서 최종 범위를 바꿀 수 있습니다.

## 보고서 필터를 적용하지 않는 경로

- **사진·PDF 원본 다운로드**: `repository.ts`의 `downloadFile`. 해당 스타일 접근 권한에 따라 원래 이름·바이너리 그대로 내려받습니다. 업로드된 업무 증빙을 재작성하거나 이름을 자동 변경하지 않습니다.
- **원부자재 컨펌 사진 다운로드**: `MaterialReviewPanel.tsx`도 같은 비공개 원본 다운로드를 사용합니다. 차수별 제출·검토 이미지 참조는 보존하며 목록 필터로 과거 파일을 수정하지 않습니다.
- **ORDER QTY 원본 정보**: `OrderSourcePanel.tsx`는 저장된 지정 열을 화면에서 확인·수정하는 기능이며 별도 Excel·CSV 다운로드 경로가 없습니다. A·M·L열 값과 기존 스타일·컬러 연결은 자동으로 재작성하지 않습니다.
- **대표 이미지 미리보기**: `image-cache.ts`, `StyleImageManager.tsx`의 Object URL은 이미지 표시용이며 파일 내보내기가 아닙니다.
- **암호화 전체 백업·복원**: `scripts/backup-workspace.mjs`는 전체 데이터베이스·파일을 보존하는 운영 도구입니다. 목록의 필터를 적용하거나 부분 백업으로 바꾸지 않습니다.
- **오더 Excel·CSV 업로드 및 기본 을지 양식 로딩**: 파일을 읽는 입력 경로이며 프로젝트별 보고서 출력 기능이 아닙니다.

## 공통 구현과 권한

- `project-identity.ts`: 공식 명칭·코드 조회, 명칭 누락 시 코드 표시, 중복 명칭 구분, ID 기반 선택·정렬.
- `settlement-export-scope.ts`: 현재 조회 가능한 스타일·컬러와 프로젝트·품번 선택의 교집합, 과거 차수 프로젝트 구분.
- `export.ts`: 오버뷰·샘플·메인 생산·결제 목록의 Excel·CSV 공통 생성.
- `sig-eulji.ts`, `production-ledger-export.ts`, `settlement-template.ts`: 고정·확정 금액과 별도 프로젝트 안내 정보를 구분해 작성.

기존 승인·활성 상태, 공장 배정과 스타일 접근 범위를 그대로 사용합니다. 프로젝트 명칭 조회나 필터로 접근 범위를 넓히지 않습니다. 운영 데이터베이스와 SQL은 이 조사에서 실행하거나 변경하지 않았습니다.
