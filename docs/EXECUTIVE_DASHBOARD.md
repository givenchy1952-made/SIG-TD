# 입고현황

본사 관리자·직원 계정으로 왼쪽 메뉴의 **입고현황**을 열면 월별 입고 일정, 국내·해외 구분, 생산국별 잔량을 함께 확인합니다. 기존 오버뷰와 분리된 화면으로, 회의 중 사이트를 함께 보며 수량과 일정을 확인할 수 있습니다. 첨부 예시의 숫자를 고정 표시하지 않고 등록된 생산 오더·부분 납기·입고 기록으로 집계합니다. 외부 업체 계정에는 이 메뉴와 본사 전체 현황을 제공하지 않습니다.

## 조회 조건 선택

화면 상단에서 시작 월·종료 월과 프로젝트 명칭·시즌·생산 공장을 선택합니다. 처음에는 이번 달부터 5개월을 표시하고, 한 번에 최대 36개월까지 조회합니다. **필터 초기화**를 누르면 초기 조건으로 돌아갑니다.

입고현황의 필터는 오버뷰·샘플 관리·메인 생산의 스타일 목록 검색·필터와 별도로 사용합니다. 프로젝트 명칭이 같은 경우에도 기존 프로젝트 ID로 구분하며, 내부 예산 관리 코드를 프로젝트 명칭으로 대신 사용하지 않습니다.

월별 표와 그래프는 연도가 바뀌어도 날짜 순서로 표시하고, 수량이 없는 월도 0장으로 남깁니다. 기준일은 한국 시간 기준입니다. 기간 합계와 현재 생산 잔량은 집계 범위가 다르므로 각각의 설명을 함께 확인합니다.

## 수량을 읽는 기준

| 항목 | 의미 |
| --- | --- |
| 원래 입고 계획 | 생산 오더와 유효한 부분 납기에 기록된 날짜별 계획 수량 |
| 입고 예정 잔량 | 기준일까지 확인된 입고를 반영한, 해당 납기월의 남은 수량 |
| 확인된 실입고 | 기록된 실제 입고일에 따른 수량. 무효 처리된 입고는 제외 |
| 현재 미입고 잔량 | 조회 월 안의 수량만이 아니라, 선택한 프로젝트·시즌·공장의 현재 미입고 오더 잔량 |
| 생산 중 / 생산 대기 | 시작·승인 근거가 있는 생산과 아직 대기 중인 발주를 구분한 잔량 |

월별 예정과 실적은 서로 다른 값입니다. 예정 물량을 실제 입고로 합산하거나 승인 대기 물량을 이미 생산 중인 물량으로 표시하지 않습니다. 생산 시작 근거가 없는 자료는 상태 확인 대상으로 구분합니다. **월별 계획·예정·실적 상세**를 펼치면 원래 계획과 잔량·실적의 정확한 수량 및 기간 합계를 볼 수 있습니다.

생산 차수·입고 원장이 있는 자료는 해당 원장을 우선합니다. 부분 납기 계획이 있으면 같은 오더의 총수량을 납기월에 다시 더하지 않습니다. 부분 납기 잔량은 실제 입고를 같은 사이즈의 빠른 납기부터 차감한 계획 잔량입니다. 같은 품번의 리오더는 기존 차수 ID로 구분하며, 스타일의 누적 수량과 차수 수량을 중복 합산하지 않습니다.

## 국내·해외와 생산국

대한민국·한국 등 확인 가능한 국내 표기를 국내로 묶고, 등록된 다른 생산국은 해외로 구분합니다. **생산국별 미입고 잔량**의 막대그래프에서 각 국가의 잔량과 비중을 비교합니다. 국가가 비어 있거나 확인할 수 없는 수량은 **국가 미지정**으로 표시합니다. 업체 이름만 보고 생산국을 추정하지 않습니다.

차수의 담당 공장은 차수에 보관된 업체 연결을 우선합니다. 생산국은 연결된 업체에 현재 등록된 국가를 기준으로 하므로, 업체 국가 정보를 과거 시점 그대로 보관한 별도 이력이 없는 자료의 과거 생산국을 복원하지 않습니다.

## 확인이 필요한 자료

차수 원장이 있는데 스타일의 기존 누적 입고 수량과 차수별 입고 합계가 다른 경우에는 확인이 필요합니다. 차수·프로젝트·월을 안전하게 연결할 수 없는 누적 입고는 임의로 배분하지 않고 **차수 배분 확인 필요 ○장**으로 별도 표시합니다. 이 안내가 있으면 확인된 실입고만 보고 전체 입고가 0이라고 판단하지 않습니다.

차수 원장이 없는 기존 누적 입고는 기록된 입고일을 기준으로 집계합니다. 이 날짜 하나만으로 과거의 여러 부분 입고 날짜를 복원하지 않습니다. 날짜 미등록, 국가 미지정, 기준일 이후의 입고 기록 등은 **집계 확인 사항**을 펼쳐 확인합니다.

입고현황은 입력 기록을 읽어 계산하며 원본 생산 오더·부분 납기·실입고·단가·마감 금액을 수정하지 않습니다.

## 현황 복사와 다운로드

화면에서 조회 조건을 정한 뒤 **현황 복사** 또는 **CSV 다운로드**를 사용합니다. 월별 국내·해외·국가 미지정 수량, 생산국별 현황, 기준일·기간과 확인이 필요한 수량을 화면과 같은 집계 기준으로 전달합니다. 자동 복사가 허용되지 않는 브라우저에서는 표시된 현황 내용을 직접 선택해 복사합니다. 내부 프로젝트 예산 코드나 업체별 단가를 내보내기에 포함하지 않습니다.

요약과 내보내기는 집계 편의 기능입니다. 실제 입고 누락이나 배분 불일치를 발견하면 생산 차수·입고 기록에서 담당자가 원본을 확인해야 합니다. 입고현황 화면을 위해 운영 SQL을 실행하거나 신규 데이터베이스 구조를 추가하지 않습니다.
