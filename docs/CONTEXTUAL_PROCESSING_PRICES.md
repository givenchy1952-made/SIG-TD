# 가공·품질 작업에서 단가 직접 입력

라벨·자수 작업과 품질 검사 안에 **작업 단가 / 검사 단가** 입력칸을 표시합니다. 별도의 단가 표로 이동하지 않고 담당 업체와 컬러를 확인하면서 이 오더의 단가를 저장합니다. 기존 **가공·품질 단가** 전체 목록도 유지합니다.

## 라벨·자수 단가

1. 스타일 상세의 **가공·품질 관리 → 라벨 관리 / 자수 관리**를 엽니다.
2. 담당 업체가 중화라벨 또는 비와이 자수 등 실제 작업 업체인지 확인합니다. 업체 이름으로 자동 배정하지 않습니다.
3. 작업 행 안의 **작업 단가**에서 업체명·컬러와 단위를 확인하고 숫자 입력칸에 단가를 입력합니다.
4. **단가 변경 사유**를 입력하고 **작업 단가 저장**을 누릅니다.

단가는 스타일·컬러·작업별로 구분합니다. 한 컬러의 단가만 수정하면 다른 컬러나 다른 작업의 단가는 바뀌지 않습니다. 빈칸은 미입력이고 `0`은 0원입니다. 단가는 부가세 제외 원화이며 소수 둘째 자리까지 입력합니다.

신규 작업이나 수정 중인 작업은 먼저 **라벨 내역 저장 / 자수 내역 저장**으로 작업을 저장해야 합니다. 단가 입력칸은 이때도 보이지만, 작업이 저장되기 전에는 비활성화하고 필요한 다음 동작을 안내합니다.

## 에이블·KOTITI 검사 단가

1. **가공·품질 관리 → 품질 검사**에서 컬러와 검사 대상 품목을 저장합니다.
2. **검사 업체 지정**에서 에이블 또는 KOTITI를 지정하고 저장합니다.
3. 같은 검사 화면의 **검사 단가**에서 현재 지정 업체·컬러를 확인한 뒤 단가를 입력합니다.
4. 사유를 입력하고 **작업 단가 저장**을 누릅니다.

미지정인 경우에도 입력칸과 지정 안내를 표시하지만 단가 저장은 막습니다. 업체가 바뀌었는데 이전 업체의 견적만 남아 있다면 그 값을 새 업체 견적으로 쓰지 않습니다. 기존 단가는 보존하고, 업체 지정 영역에서 현재 업체의 기준 단가를 확인·적용한 뒤 필요한 개별 단가를 수정합니다.

검사 업체 계정은 기존 검사 전용 화면에서 자기 업체의 기준 단가를 관리합니다. 이 오더의 합의 단가 저장은 본사에서 관리하며, 미지정 오더나 다른 검사 업체의 오더를 공개하지 않습니다.

## 공통 기본 단가와 이 오더 단가

**업체 공통 작업·기본 단가**는 다음 스타일이나 새 작업에 재사용할 기준값입니다. **작업 단가 / 검사 단가**는 현재 스타일·컬러·작업의 저장 견적입니다. 업체 기본 단가를 올려도 기존 오더의 저장 단가는 자동으로 바뀌지 않습니다.

을지는 현재 작업에 저장된 단가를 N열에 사용합니다. 라벨의 R열은 실출고 수량, 자수·품질 검사의 R열은 실입고 수량을 사용합니다. 단가 입력으로 오더·출고·입고 수량이나 기존 고정 양식의 수식·부가세·합계를 바꾸지 않습니다.

## 저장 보호와 설정

- 다른 작업이나 단가를 편집 중이면 먼저 저장하거나 취소하도록 안내합니다. 편집 중 상세 화면을 닫을 때도 미저장 내용을 보호합니다.
- 다른 사용자가 단가·담당 업체·작업을 변경하면 기존 입력은 유지하고 오래된 값의 저장을 막습니다. 취소 후 최신 내역을 확인합니다.
- 결제 마감된 업체별 합의 단가는 보존합니다. 단가를 저장한 뒤 화면 갱신이 실패하면 재저장 대신 다시 불러오도록 안내합니다.
- 입력이 비활성화되면 바로 아래 안내에서 작업 미저장, 검사 업체 미지정, 기능 설정 누락, 편집 충돌 등의 이유를 확인합니다.

이번 입력 화면 개선은 기존 단가 저장 API를 재사용하며 **신규 SQL을 추가하지 않습니다**. 기존 단가 저장은 SQL013, 검사 업체 지정과 업체 공통 작업·단가는 SQL020·021이 적용되어 있어야 합니다. 기존 SQL 적용이나 운영 배포가 완료되었다는 뜻은 아니며, 운영 SQL은 이 개발 작업에서 자동 실행하지 않습니다.
