# 컬러별 전체 품번과 CSV 담당자

F열의 `BP06FYHD0402BL` 전체 품번을 읽어 기본 품번 `BP06FYHD0402`와 컬러 `BL`을 함께 보존합니다. I열은 읽지 않습니다. 메인 화면의 품번은 컬러를 포함하며, 같은 기본 품번의 BL·BK는 각각 한 줄로 표시합니다. 검색·컬러·담당자 필터와 수량은 해당 컬러를 기준으로 작동합니다. 상단 스타일 집계는 중복 없는 기본 스타일 수이며 목록에는 스타일 수와 컬러 행 수를 함께 표시합니다.

담당자는 CSV Y열의 이름 또는 이메일이 승인된 활성 본사 계정과 유일하게 일치할 때 자동 연결합니다. 동명이인·미등록 이름은 **업로드 기본 설정**에서 해당 이름을 한 번 연결합니다. 빈 Y열은 담당자 미지정으로 등록하고 업로더로 채우지 않습니다. 기존 품번을 다시 업로드해도 업로드한 컬러의 담당자는 Y열을 따르며 다른 컬러의 담당자는 보존합니다.

수동 배정은 **품번 클릭 → 메인 생산 → 해당 컬러 → 본사 담당자 선택 → 변경 사유 → 변경 저장**으로 진행합니다. 기본 정보의 본사 담당자는 기존 자료의 공통 담당자이며, CSV로 명시한 컬러별 담당자를 덮어쓰지 않습니다. 미지정 상태로 오더·생산 차수를 만들 수 있지만 마감 확정 전에는 본사 담당자를 배정해야 합니다. 이미 담당자가 기록된 과거 차수와 확정 마감의 담당자는 변경하지 않습니다.

## 운영 프로젝트에 적용

기존 001~009 설정을 적용한 프로젝트에서 다음 파일만 순서대로 실행합니다. 이미 적용한 초기 SQL을 다시 실행하지 않습니다.

1. [010_member_withdrawal.sql](../supabase/migrations/010_member_withdrawal.sql) — 관리자 구성원 탈퇴와 이력 보존.
2. [011_import_color_owners.sql](../supabase/migrations/011_import_color_owners.sql) — 컬러별 담당자와 담당자 미지정 오더·차수.

[Supabase SQL Editor](https://supabase.com/dashboard/project/phmuweuwjyzbziqlpplz/sql/new)에서 각 파일의 전체 내용을 붙여 넣고 실행합니다. 두 SQL은 재실행할 수 있으며 기존 품번·수량·확정 금액을 일괄 변경하지 않습니다. 011은 기존 생산 차수 테이블이 필요하므로 007~009 미적용 오류가 있으면 먼저 해당 설정을 완료합니다.

Vercel의 `sig-td` 프로젝트에서 이 변경이 포함된 최신 main 배포가 Ready인지 확인한 뒤 사이트를 새로고침합니다. SQL 설정과 앱 배포가 모두 필요합니다. 미적용 상태에서는 구성원 탈퇴와 컬러별 담당자 업로드에 설정 안내를 표시합니다.

## 을지와 다운로드

제품·품질검사의 담당자는 선택한 컬러의 담당자이며, 미지정이면 W열도 빈칸입니다. 라벨·자수는 스타일 공통 작업을 중복 계산하지 않으며 선택 컬러의 담당자가 서로 다르면 W를 비워 담당자가 작성할 수 있게 합니다. 과거 확정 차수는 보존된 담당자를 그대로 사용합니다.

가입자 탈퇴·복구 절차는 [구성원 탈퇴 안내](MEMBER_WITHDRAWAL.md)를 확인하세요.
